运行环境检查与使用说明
程序自带 Python、PyTorch 与 FFmpeg，无需安装 Python 或 CUDA Toolkit。当前版本适用于 Windows 10/11 x64、NVIDIA RTX 显卡及兼容 CUDA 13 的驱动。H3 入门参数已在 RTX 3060 12GB / 32GB RAM 上验证；其他硬件请先运行检查。原图回贴普通处理可使用 CPU。
